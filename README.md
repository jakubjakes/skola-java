# Školní projekty – Java

Objektově orientované programování v Javě. Jsou to školní cvičení a menší projekty.

| Projekt | Co dělá |
|---|---|
| `hrdina_dedicnost/` | Textová hra s hrdiny (rytíř, kouzelník), nepřáteli a lokacemi. Ukazuje **dědičnost** a polymorfismus. |
| `simici/` | Simulace domácnosti ve stylu Simíků: potřeby, předměty, jídlo a elektronika. |
| `vesmirna stanice/` | Vesmírná stanice, která řídí drony a těží asteroidy. |
| `mycka/` | Autoservis s myčkou: zákazníci, auta a mycí boxy. |
| `servis IT/` | IT servis: technici, zákazníci a opravovaná zařízení. |
| `autoservis/` | Jednoduchá evidence aut v servisu. |
| `Tamagochi/`, `tamagochi.java` | Virtuální mazlíček. |
| `Farmig_simulator.java` | Jednoduchý farmářský simulátor. |
| `obchod_s_kouzly.java` | Obchod s kouzly. |
| `Mavenproject1.java` | Caesarova šifra: šifrování a dešifrování textu posunem v abecedě. |

## Spuštění

Většina projektů je jedna složka nebo jeden soubor. Stačí je zkompilovat a spustit třídu s metodou `main`:

```bash
cd mycka
javac *.java
java Mycka
```

Projekty `hrdina_dedicnost` a `simici` jsou v balíčcích (`com.mycompany...`), protože vznikly v NetBeans. Nejsnáz se spustí, když je otevřeš v IDE.
